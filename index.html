  1. Entrá a console.firebase.google.com y creá un proyecto (gratis)
  2. Compilación → Firestore Database → crear base de datos → modo de prueba
  3. ⚙️ Configuración del proyecto → Tus apps → agregar app web (ícono </>)
  4. Copiá el objeto firebaseConfig que te muestra y pegalo abajo
