🎡 ¿Cómo se juega?

🎯Girá la rueda. El tema donde caiga te tira una pregunta de opción múltiple.
📈Cada tema tiene su propio nivel (1 a 15). Si acertás, sube; si fallás, baja un poco.
🎲Tenés 4 comodines por pregunta: 50/50, Pasar, Doble o nada, y Pista — te ayudan cuando te trabás.
☰En "Más opciones" están el resto de los modos: multijugador, torneo, supervivencia, desafío diario, tus estadísticas y logros, y más.
💾Todo tu progreso queda guardado en este dispositivo — no hace falta cuenta ni internet para jugar.

Clave de API de Gemini

Fuera de Claude.ai, la generación de preguntas usa la API de Gemini (Google AI Studio) directamente desde el navegador. Consíguela en aistudio.google.com → Get API key. Se guarda solo en este dispositivo.

💾 Exportar / importar banco

Guardá tus preguntas generadas por IA y las que escribiste vos en un archivo, para no perderlas si cambiás de dispositivo o reinstalás la app.
